# ADR-0005：前端多语言，后端错误消息保持中文

> 状态：**已采纳**（2026-10-17，用户明确决定）
> 关联：`docs/tasks/P4-03-user-requested-features.md` §2、§9 第 3 项；`AGENTS.md` 硬性规则 3

---

## 1. 背景

用户要求界面支持**中文 / 日语 / 英语**三语切换。

做多语言时撞上一个隐藏成本：**Rust 侧的错误消息也是用户可见的**。
`commands/` 下的 9 个命令返回 `Result<T, String>`，错误串是硬编码中文，例如：

- `add_account` → `"无法识别该邮箱服务商：…"`
- `sync_folder` → `"登录失败：…"`
- `send_mail` → `"附件总大小超过 25 MiB"`

前端拿到后直接 `String(err)` 显示。也就是说：**界面切成英文，一出错还是中文。**

要让这些也跟随语言，必须改 `commands/` 的返回契约 —— 从返回成品字符串
改成返回错误码 + 参数（如 `{ code: "provider_unknown", params: { email } }`），
由前端翻译。这会影响全部 9 个命令、每一个调用点、以及所有针对错误串的断言。

---

## 2. 决策

**本次只做前端多语言；`commands/` 的返回契约保持不变，错误消息继续是中文。**

用户的原话是：

> 「多语言只有极少部分地方报错……是中文的话是没问题的」

因此这是**知情取舍**，不是遗漏。README / 交接文档里必须如实写明这条边界，
不能对外声称「完整支持三语」。

### 2.1 为什么不同时改后端

| 理由 | 说明 |
| --- | --- |
| 风险与收益不成比例 | 9 个命令 + 全部调用点 + 现有错误断言全要动，只为翻译几十条几乎不会同时出现的报错 |
| 报错本来就是例外路径 | 正常使用时一条都不会看到；看到时通常已经在求助，此时中文反而便于我按原话检索文档 |
| `AGENTS.md` 硬性规则 3 | 「接口签名变更」属于**必须暂停并询问**的四类情形之一，而用户当时的选择是「不动契约」 |
| 真要做有正确顺序 | 应当先统一后端的错误类型（`thiserror` 已有，但被 `to_string()` 抹平了结构），再加前端翻译层。顺序反了会写出一堆临时映射 |

### 2.2 明确拒绝的方案：前端按字符串匹配翻译

把中文错误串当 key 去查词典。

**拒绝理由：那是把 UI 文案当接口用。** 后端改一个字（甚至改标点）前端就静默失配，
而且失配时是「悄悄回退成中文」，测试也不会红 —— 违反本项目「文档/状态必须与代码一致」的原则。

---

## 3. 后果

### 3.1 好的

- 零新增依赖：一门语言一个纯对象 + 一个 `{}` 插值函数，完整性靠 TypeScript
  （`ja` / `en` 被约束成 `Record<Key, string>`，**漏译即 `tsc` 报错**）
- 语言的地区码与文案同源，`toLocaleString` 的日期格式自动跟随
  （`zh-CN` / `ja-JP` / `en-US`）
- 语言选择存在 `localStorage`，与主题同一模式，不涉及凭证

### 3.2 代价 / 已知边界

| 边界 | 影响 |
| --- | --- |
| **Rust 错误消息恒为中文** | 界面是英/日时，出错提示仍是中文。这是本 ADR 的核心取舍 |
| 邮件内容本身不翻译 | 用户邮件是什么语言就是什么语言；正文翻译需求**已被用户撤回**（见 P4-03 §7），不得据本 ADR 重启 |
| 服务商名称不翻译 | `provider_name` 来自 `mail/provider.rs`（如「网易163邮箱」），是企业/品牌名，按惯例不译 |
| 文件夹名不翻译 | `INBOX`、`已发送` 等来自 IMAP 服务器，是**服务器给的用户数据**，不是 UI 文案 |
| 非拉丁语言的断行 | 日语无空格，靠 `<html lang>` 让浏览器选断词规则；已随语言切换写入 |

---

## 4. 若日后要补上后端多语言

按此顺序，不要跳步：

1. 给 `commands/` 的每个错误定义枚举（`thiserror` 已有基础，但目前被 `.to_string()` 抹平）；
2. 命令返回 `{ code, params }` 而非 `String` —— **这是接口签名变更，须重新征得用户同意**；
3. 前端加 `error.<code>` 命名空间到三份词典；
4. 把现有针对错误串的断言改成断言错误码；
5. 保留中文作为最终兜底：**未知 code 显示中文原文**，好过显示 `undefined`。

逐栏核对文案、并确认切换后日期格式随地区变化。
